# LabBook – Materiale delle lezioni

Progetto **LabBook**: applicazione web per la prenotazione dei laboratori dell'IIS "G. Marconi".
Modulo *Soft Skills Lab 4.0* – POC Orientamento 4.0.

## Come scaricare il materiale
1. Clicca sul file `.zip` della lezione.
2. Clicca su **Download raw file** (icona con la freccia in basso, a destra).
3. Scompatta lo zip, per esempio sul Desktop.

## Come aprire i progetti in NetBeans

**tappa1-regole** (solo per chi non ha più il progetto di ieri)
1. File → New Project → Java with Ant → Java Application
2. Crea il package `labbook` e copia dentro i file `.java`
3. Tasto destro su `ProvaRegole` → Run File

**tappa2-prima-pagina** (progetto web)
1. File → Open Project → cartella `tappa2-prima-pagina`
2. Tasto destro → Properties → Build → Compile → Java Platform: **JDK 21**
3. Tasto destro → Run, attendi `Started LabBookApplication`
4. Apri il browser su http://localhost:8080/laboratori
